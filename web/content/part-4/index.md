# 第四篇：数据处理与质量控制

从网页与文本出发，串联正文提取、语种识别、隐私处理、精确去重和 MinHash，再通过训练评价数据质量。

<div class="learning-guide">

**贯穿本篇的路线**

抽样理解数据 → 实现各项过滤 → 去重 → 编码训练 → 固定验证集比较。

</div>

## 按处理流程阅读

本篇对应[第 10 章 · 数据处理与质量控制](./chapter-10)。

| 环节 | 阅读重点 |
| :--- | :--- |
| 网页文本提取 | 区分 WARC、WAT、WET，理解 HTML 正文提取与解析工具的用途。 |
| 语种识别与隐私处理 | fastText、N-gram、语言置信度，以及隐私掩码中的误报与漏报。 |
| MinHash 与 LSH | 从 Jaccard 相似度到签名矩阵、分段、哈希桶与候选对。 |
| 精确去重与语义去重 | 区分完全相同、字面近似和语义相似的文本，理解各类方法。 |
| 数据处理综合实验 | 获取 Common Crawl WET 数据，过滤、合并、分词、训练并观察结果。 |

## 贯穿全篇的作业

Assignment 4：完成过滤流水线，生成训练 token 数据，在固定模型与训练流程下比较过滤策略。

原稿记录了获取数据、过滤处理、分词与训练的实践，包含处理流程、过滤结果和训练曲线。数据和作业仓库见[数据与实验入口](./resources)。

::: tip 先确认数据处于哪一步
WARC 包含原始网页，WET 是已经提取出的纯文本。本篇综合实验使用 WET；HTML 提取环节的输入与它不同。Paloma 用于验证，原稿自行处理的验证数据也需要记录版本和划分方式。
:::
